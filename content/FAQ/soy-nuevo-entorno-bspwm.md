# ¿Es obligatorio tener el entorno BSPWM para seguir los cursos?

**No es obligatorio.** Puedes realizar los cursos de la academia sin necesidad de tener un entorno BSPWM.

# ¿Debo tener una base en Linux para instalarlo?

**Se recomienda instalarlo cuando ya tengas una buena base en Linux**, ya que sabrás lo que estás haciendo: instalar paquetes, modificar la configuración del entorno, arreglar errores, entre otras tareas. Este artículo sigue el [roadmap](https://hack4u.io/roadmap/) de la academia, donde primero se invita al usuario a realizar el curso de [Introducción a Linux](https://hack4u.io/cursos/introduccion-a-linux/) y, posteriormente, pasar a la fase de personalización (curso no obligatorio). 

# AutoBSPWM. ¿Debo usarlos?
Los *AutoBSPWM* son repositorios de la comunidad que mediante un simple script permiten montar el entorno de manera automática. **No se recomienda intentar instalar uno sin tener nociones de Linux**, ya que podría fallar y causarte complicaciones.

# No soy estudiante en la academia. ¿Cómo aprendo Linux?

Puedes aprender Linux a través de muchas fuentes. A continuación, te presentamos algunos recursos recomendados:

- [Introducción a Linux Hack4u](https://hack4u.io/cursos/introduccion-a-linux/) -> Se requiere tener pagada alguna membresia. Este curso te dará una buena base solida de Linux.

- [Linux Fundamentals HackTheBox Academy](https://academy.hackthebox.com/module/details/18) -> Se requiere una cuenta, es gratuito ya que HackTheBox te da unos puntos iniciales donde los podrás canjear en este módulo. (Este recurso está en ingles)

- [Scripting en Bash para principiantes #1](https://youtu.be/RUorAzaDftg) -> Video antiguo de s4vitar pero válido para aprender Linux. En el estará resolviendo los ejercicicios de [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) que se recomienda para gente que está empezando en Linux.

# ¿Y cómo sé cuándo puedo instalar un entorno?
Cuando ya sepas **moverte con soltura por el sistema Linux**, seas **capaz de solucionar errores por tu cuenta** utilizando herramientas como ChatGPT, Google u otras, y entiendas exactamente lo que estás haciendo en lugar de ejecutar comandos sin conocimiento.

>[!WARNING]
> Desde este artículo no te prohibimos instalar un entorno como BSPWM, eres libre de hacerlo cuando quieras. Simplemente aconsejamos no intentarlo si eres principiante y aún no tienes nociones de Linux, para evitar que pierdas tiempo y te frustres en el proceso.
